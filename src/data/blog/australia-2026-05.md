因为初中一起搞乐队的好朋友 C 君在澳洲生活，我也一直没去过澳洲，而且上次见面已经是 2020 年（估计），所以从 2024 年就一直想着要去澳洲拜访一下老朋友再随便转转。但也因为种种生活的琐碎，一直拖着没去。2025 年我还跟 C 君说，“2026 我一定要去澳大利亚”，2026 年终于成行。

## 2026-05-01

下午从成田机场出发，乘坐飞机到厦门转机，晚上十点再从厦门飞到墨尔本。

![](@/assets/images/australia-2026-05/7.jpeg)

![](@/assets/images/australia-2026-05/11.jpeg)

很幸运的在厦门飞墨尔本的飞机上被分配到了过道且后面没人的座位，随便后躺随便上厕所。

![](@/assets/images/australia-2026-05/16.jpeg)

## 2026-05-02

早晨八九点到达墨尔本，丝滑入境。C 君计划开车来接我，但是没算到我出来这么快，于是我在到达口等了 C 君一会。回回消息，跟家人朋友报个平安。算着 C 君快要到了，我就开始四处张望，很是期待和专心。

![](@/assets/images/australia-2026-05/17.jpeg)

我抢在 C 君发现我之前，隔着老远一眼就认出来了了他，虽然他造型变化巨大。拥抱寒暄之后一起走向停车场，又经过及其复杂的路途找到了车。登上 C 君的车，正式开始墨尔本之旅。

开车到了墨尔本大学旁边，因为我的行李要丢在车里，C 君专门找了个安全的停车场停车。然后到 C 君精选的一家 Brunch 店开吃。喝了第一杯澳洲特产 Flat White。真是从来没尝试过荤的三明治加果酱和糖浆，本来以为很黑暗，但其实还有点惊艳。

![](@/assets/images/australia-2026-05/21.jpeg)

刚到墨尔本以及从机场到市区的路上，真没发现澳洲或者墨尔本的特点，就感觉跟美国差不多。饭后在墨尔本大学附近走了走，发现这的建筑是又凌乱又有个性，想怎么修就怎么修，非常艺术，又透露着非常有钱的感觉。

## 2026-05-06

早餐六点半起床，告别了 C 君的大豪斯，C 君开车送我去机场。又走过了熟悉的街道，熟悉的 “凯旋门”，经过熟悉的 West Gate Bridge，跨过熟悉的 Yarra River ... 距离机场还有差不多十分钟时，刚好音乐播放到了经典的 Beyond 的海阔天空（也不知是不是 C 君提前安排好的），我们一起在车里纵情放声高歌了一把，破音也无所谓了。拥抱告别，希望彼此都好，期待下次相见。

![](@/assets/images/australia-2026-05/232.jpeg)
<figure class="-mt-6">
  <figcaption class="text-center">墨尔本机场出发口</figcaption>
</figure>

说起来，我们初中时的乐队叫六芒星，我弹贝斯（因为我其实也没咋好好学过乐器），C 君是主唱，我们没少排练了 Beyond 的歌曲。C 君当时音乐品味非常先锋，非常独立，带着我听了好多诸如枪花、Metallica、Nirvana、David Bowie、李志、舌头乐队之类的金歌劲曲，我最爱的乐队 Pink Floyd 也是 C 君推荐给我的，可以说我的音乐品味深受 C 君影响。这次来墨尔本之前我在脑中幻想了好多次坐在 C 君的车里，一起听着以前喜欢的音乐，一起 KTV。但是真没想到，C 君最近几年喜欢上了爱情歌，C 君说在一些情感变故之后，他开始理解这些歌的歌词所描写的情感了。

![](@/assets/images/australia-2026-05/241.jpeg)
<figure class="-mt-6">
  <figcaption class="text-center">六芒星乐队在表演 Beyond 歌曲（具体时间忘记了，大约在 2014 - 2016）</figcaption>
</figure>
